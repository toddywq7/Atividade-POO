Sobre o Projeto
Sistema para movimentação segura de contas bancárias da fintech NuBanko, desenvolvido para evitar inconsistências e alterações diretas no saldo. Tipos de Conta e RegrasPoupança: Não possui limite extra e não pode ficar com saldo negativo. Corrente: Permite saldo negativo utilizando um limite emergencial pré-aprovado. Empresarial: Pode utilizar limite de crédito, mas exige o pagamento de uma taxa de R$ 5,00 a cada saque. Regras Gerais e SegurançaO saldo inicial de toda conta é zero. Todo depósito deve ser obrigatoriamente maior que zero. Encapsulamento: Não existe o método setSaldo(). Isso impede que programadores alterem o saldo diretamente de forma indevida. As reduções de saldo ocorrem apenas de forma segura através do método protected debitar(). Conceitos de POO AplicadosAbstração e Herança: A classe principal ContaBancaria é abstrata, definindo a estrutura base (número, titular, saldo, depósito) que é herdada pelas contas específicas. Polimorfismo: O método sacar() é abstrato na classe mãe, forçando cada tipo de conta a implementar sua própria regra de saque.
